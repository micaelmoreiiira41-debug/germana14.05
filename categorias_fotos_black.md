# Categorias de Fotos - Modelo Black

Biblioteca de prompts para criação de imagens no estilo da ID visual `black`.

Use este arquivo como referência ao criar imagens de acordo com o tema da peça. Todas as imagens devem preservar estética premium, editorial, escura, cinematográfica, com boa área para texto quando o formato exigir.

Regra fixa de figurino: médicas devem sempre aparecer com roupa clara ou branca, preferencialmente jaleco branco, blazer claro, camisa clara ou composição médica clara. Evitar roupa preta/escura em médicas, mesmo dentro da estética `black`.
